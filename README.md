I'm a computer science student from Taiwan, currently serving as the software lead / CTO role in Dongyu Technology, a student-led AIoT startup team.

## Engineering Style

I care about clarity, aesthetics, and maintainable architecture.

I enjoy working close to the full product loop:

1. Understand the problem
2. Design the system
3. Build the prototype
4. Test the weak points
5. Improve the architecture
6. Repeat

I use AI tools to accelerate my workflow, but I prefer a top-down approach so the architecture stays intentional instead of becoming a pile of generated code.

My strongest area is connecting different layers together:

- UI / UX
- App logic
- Backend APIs
- Database design
- Device communication
- Hardware constraints
- Product requirements

I am still learning many of these fields deeply, but I enjoy working at the intersection where they meet.
